<p>要说哪种出口更稳定，先得说清"稳定"量的是什么。延迟低不等于稳定，带宽大也不等于稳定，真正影响使用体验的是三件事：延迟波动有多小、出口身份会不会变、断了之后多久能回来。为了把这三件事测出来，我按同一套动作跑了两组出口七天：一组是固定家庭宽带，一组是手机蜂窝网络，同一台设备、同一时段、同一批请求。下面先讲实验怎么设的，再分别看延迟、身份、掉线三组数据，最后给出按使用形态分派的结论。</p>

<h2>一、实验设计：两组出口，同一套动作</h2>
<p>实验的公平性来自控制变量：设备、系统版本、客户端配置、测试时段全部相同，只有出口这一项不同。每组连续跑七天，每天三个时段，每时段跑一轮。</p>
<h3>三个时段与两类探针</h3>
<p>时段选在 10:00、20:00、23:00，分别代表工作时段、晚高峰与深夜。探针分两类：ICMP 用来看链路往返与丢包，应用层请求用来看真实的握手与首字节耗时。后者更接近体感。</p>
<h3>记录的四类数据</h3>
<p>延迟中位数与九十五分位、丢包率、出口地址变化次数、以及每次断连到恢复的秒数。四项分开记，避免用一个综合分把差异抹平。</p>

<h2>二、延迟与抖动：移动网络的优势和代价</h2>
<p>单看中位数，蜂窝在部分地区反而更低，因为基站离用户近、路由跳数少。但抖动明显更大，尤其是在移动状态下，切换基站会带来几百毫秒的瞬时抬升。</p>

<h3>中位数相差不大，尾部差别明显</h3>
<p>七天数据里，家宽的九十五分位通常落在中位数的一点三倍以内，蜂窝能到两倍以上。日常对话感受不到差别，但长回复的流式输出会在这里暴露：尾部延迟高的那一组更容易出现停顿。</p>
<h3>晚高峰是分水岭</h3>
<p>二十点之后，蜂窝的抖动普遍放大，因为同一基站下的用户都在用。家宽也会受上游影响，但幅度更平缓。如果你的主要使用时段在晚间，这一项的权重应该提高。</p>

<h2>三、出口身份稳定性：固定的家宽与漂移的蜂窝</h2>
<p>这一组差异比延迟更值得关注，因为它决定了环境是否连续。家宽的地址在七天内只变过一次，还是因为手动重启了光猫；蜂窝在同样七天里变了十几次。</p>
<h3>蜂窝为什么会频繁变化</h3>
<p>移动网络普遍使用地址转换，多个用户共享少量公网地址，重连、跨基站、长时间空闲后重新附着都可能分配到不同出口。这不是故障，是网络架构决定的常态。</p>
<h3>变化带来的连锁反应</h3>
<p>地址一变，服务端看到的登录地就变了。变化不频繁时只是偶尔要求验证，变化密集时会打断正在进行的长会话。附件上传这类耗时操作，最容易在切换中被截断。</p>
<h3>能不能把身份固定下来</h3>
<p>可以借助一条固定出口做通道，让应用侧看到的地址不随物理网络变化。代价是多一跳，延迟增加几十毫秒，换来的是身份连续性。是否值得，取决于你对连续性的依赖程度。</p>

<h2>四、掉线与重连：关键时刻谁先掉链子</h2>
<p>两组的掉线次数都很少，差别在恢复速度。家宽断开后通常需要人工介入，比如重启设备；蜂窝往往能自动重新附着，但重新附着的过程不受你控制。</p>
<h3>恢复时间的量级差异</h3>
<p>家宽线缆或设备问题，恢复以分钟到小时计；蜂窝在信号良好区域重新附着通常在十秒级，但信号弱时可能反复尝试。前者慢但可预期，后者快但不确定。</p>
<h3>重连后的状态是否一致</h3>
<p>重连之后要检查三件事：出口地址是否变化、会话是否需要重新建立、客户端连接池里的旧连接是否已失效。第三项最容易被忽略，表现为重连后前几个请求往往失败。</p>
<h3>加一层兜底</h3>
<p>两条物理链路互为备份，是少见的能把恢复时间压到秒级的做法。成本是双份带宽，收益是关键时刻不中断。是否上这套方案，取决于中断一小时的实际损失。</p>

<h2>五、结论落在使用形态上</h2>
<p>数据摆完，答案不是"哪个更好"，而是"哪个更适合你的用法"。固定场景、长时间连续操作，家宽占优；移动场景、短时高频，蜂窝的便利性无法替代。</p>
<h3>固定场景优先家宽</h3>
<p>办公位、家里书桌这类固定位置，用有线或固定 Wi-Fi 出口，配合一条稳定的通道，环境连续性最好。这类场景对上行带宽要求不高，对稳定性要求高。</p>
<h3>移动场景接受漂移或加通道</h3>
<p>经常在外的人，要么接受地址变化带来的额外验证，要么用固定通道把变化挡在外面。前者省钱，后者省心，两者都不算错，只要预期对齐。</p>
<h3>关键操作挑时段与场景</h3>
<p>支付、首次登录、重要提交这类操作，安排在固定网络下完成，避开移动状态和晚高峰。这条建议不需要额外成本，却能消掉相当一部分偶发失败。</p>

<h2>常见问答</h2>
<h3>蜂窝延迟更低，为什么还说家宽更稳？</h3>
<p>答：稳不稳看的是波动和身份连续性，不是中位数。蜂窝在理想条件下延迟可以更低，但抖动大、地址变化频繁，长时间连续操作时反而更容易被打断。</p>
<h3>家庭宽带的地址会不会自己变？</h3>
<p>答：会，但频率低。常见触发是设备重启、线路维护、租期到期续约。若发现短期内多次变化，先查设备日志与运营商侧是否有调整。</p>
<h3>两条链路互备成本高吗？</h3>
<p>答：取决于你对中断的容忍度。双份带宽加一台能做切换的设备，是主要成本；配置与维护的复杂度也需要考虑。中断损失低于这套成本时，单链路加快速恢复更划算。</p>
<h3>这个实验的结论能直接套用到别的地区吗？</h3>
<p>答：不能。不同地区的固网质量、基站密度、运营商策略差异很大，同一套方法测出的数值会不同。方法可以照搬，结论要自己测一遍。</p>
